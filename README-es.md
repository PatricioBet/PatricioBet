### 🚀 Sobre mí

- 💻 **Enfoque principal:** Desarrollo Web Full Stack, Arquitectura Backend e IA Aplicada / Visión Artificial.
- 🏗️ **Construyendo actualmente:** 
  - Un sistema POS (Punto de Venta) integral con facturación electrónica adaptado a las normativas del mercado ecuatoriano (SRI).
  - Orquestación de agentes de IA personalizados para flujos de trabajo de programación y UI/UX.
- ⚙️ **Infraestructura:** Gestión de un *home lab* técnico utilizando Docker, herramientas de administración VPS (Dokploy) y LLMs locales a través de Ollama.
- 🏆 **Algoritmia:** Participación activa en programación competitiva (IEEEXtreme) especializándome en C++ y Python.
